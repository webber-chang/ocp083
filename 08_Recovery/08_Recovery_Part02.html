Mock Exam 3 · Question 4 還原與復原

Examine this configuration:
1. CDB1 is a container database running in ARCHIVELOG mode.
2. Multiple uncommitted transactions are running in CDB1.
3. Redo log groups 1 and 2 are INACTIVE.
4. Redo log group 3 is the CURRENT group.
All members of redo log group 3 are lost before it is archived.
Examine these possible steps:
1. SHUTDOWN ABORT
2. STARTUP NOMOUNT
3. STARTUP MOUNT
4. ALTER DATABASE MOUNT
5. RESTORE DATABSE
6. RECOVER DATABASE NOREDO
7. RECOVER DATABASE UNTIL AVAILABLE
8. RESTORE ARCHIVELOG ALL
9. ALTER DATABSE OPEN
10.ALTER DATABASE OPEB RESETLOGS
Choose the minimum required steps in the correct order to recover the database.

📘 官方解析與重點參考
📝 重點筆記參考：
RECOVER DATABASE NOREDO（復原但不套用任何重做日誌）- 這是錯誤作法

作用： 這個指令強制 Oracle 「不要套用任何 Redo Logs」。它通常只會去套用增量備份（Incremental Backups），然後就直接結束復原程序。

結果： 如果你用了這個指令，你放在備份與當前時間之間、那些明明還完好無缺的 Archived Redo Logs 都會被忽略。這會導致你流失大量的資料（從最後一次備份以來的所有的異動都會不見）。

總結來說：
在遺失 CURRENT 日誌的情況下，你應該選擇 7 (UNTIL AVAILABLE) 來盡可能榨乾剩下的日誌以救回最多資料，而不是選擇 6 (NOREDO) 直接放棄套用所有日誌。

Mock Exam 3 · Question 7 還原與復原

Which three are true about block media recovery? (Choose three.)

📘 官方解析與重點參考
📝 重點筆記參考：
E. The target database for which one or more blocks are to be recovered must be in the OPEN state. (要復原一個或多個區塊的目標資料庫必須處於 OPEN 狀態)
解釋： BMR 的設計初衷就是在「不影響線上服務」的情況下進行修復。因此，它最主要且標準的應用情境，就是當資料庫處於 OPEN 狀態、資料檔在線（Online）時，由背景即時進行損壞區塊的復原。
D. It can be performed on noncorrupt blocks. (它可以在未損壞的區塊上執行)
為何錯誤： RMAN 的 RECOVER BLOCK 指令是設計用來修復「已標記為損壞」的區塊（通常紀錄在 V$DATABASE_BLOCK_CORRUPTION 視圖中）。你不能對一個正常、沒有損壞的區塊執行區塊復原。

📘 官方解析與重點參考

A lost TEMPFILE must always be re-created manually==>contaol file有就會自動建立

遺失索引表空間雖然不會讓 DB 死機，但會讓依賴該索引的資料寫入功能癱瘓，並且讓部分查詢報錯。

Mock Exam 8 · Question 17 還原與復原

Which three are true about recovering tables using RMAN? (Choose three.)

📘 官方解析與重點參考
📝 重點筆記參考：
SYS 帳號（絕對禁區）：SYS 是資料庫最核心的帳號，擁有最底層的資料字典基表（Data Dictionary Base Tables）。為了防止核心系統崩潰，Data Pump 引擎寫死了絕對禁止匯出或匯入任何由 SYS 擁有的物件。因此，RMAN 絕對無法單獨復原 SYS 的表格。

SYSTEM 帳號（技術上允許）：SYSTEM 雖然也是極高權限的系統管理帳號，用來存放次要的系統工具或管理資料，但它並不受限於 Data Pump 的硬性阻擋。因此，從純粹的「技術能力」來看，RMAN 確實有能力透過 Data Pump 將 SYSTEM 擁有的表格匯出並復原。這就是為什麼考題答案中 "RMAN can recover tables owed by the SYSTEM user." 是正確的
