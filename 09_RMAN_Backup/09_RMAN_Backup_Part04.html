Mock Exam 7 · Question 29 RMAN

Which three are true about Recovery Manager (RMAN) in Oracle Database 19c and later releases? (Choose three.)

📘 官方解析與重點參考
📝 重點筆記參考：
It is always possible for RMAN to connect to a pluggable database as a target if any RMAN Catalog is used.
錯誤原因： 錯在後面的條件限制（if any RMAN Catalog is used）。這句話暗示了「你必須使用 RMAN Catalog 才能連線到 PDB 作為 Target」，這在 19c 中是錯誤的。即使您不使用任何 Catalog（僅依賴目標端控制檔 NOCATALOG 模式），您依然可以直接連線到 PDB。因此，不需要這個條件限制。

Mock Exam 8 · Question 7 RMAN

Which three are true about RMAN archival backups with the RESTORE POINT clause? (Choose three.)

📘 官方解析與重點參考
📝 重點筆記參考：
Archive logs are retained if they are necessary to allow the database to be recovered to a consistent state when an archival backup is restored. (如果為了讓歸檔備份還原時能將資料庫復原到一致狀態，必要的歸檔日誌將會被保留。)

您誤選的陷阱分析：
They can optionally be written to a fast recovery area (FRA). (您誤選的選項)
錯誤原因： 這是 Oracle 的硬性規定。快速復原區 (FRA) 的設計初衷是為了「短期、日常」的快速循環覆寫與自動空間管理。而 Archival Backup 是要放好幾年不能動的。如果把它放在 FRA，會永遠霸占空間並破壞 FRA 的自動清理機制。因此，Oracle 嚴格禁止將帶有 KEEP 屬性的長期備份寫入 FRA，您必須將其存放到獨立的磁碟路徑或磁帶 (SBT) 中。
