Mock Exam 5 · Question 1 RMAN

Which three are true about RMAN archival backups with the RESTORE POINT clause? (Choose three.)

📘 官方解析與重點參考
📝 重點筆記參考：
「Archival Backup (封存備份)」 和 「Archive Log (歸檔日誌)」 雖然單字長得很像，但在 Oracle 裡是完全不一樣的東西。
Archival Backup (封存備份)

這是什麼： 這是一個 「特殊的 RMAN 備份動作」。有時候因為法規要求（例如財務資料要保留 7 年），你需要把今天的資料庫做一個「時空膠囊」永久保存起來，不被日常的過期刪除機制（Retention Policy）給清掉。
對應語法： 就是前面提到的 BACKUP DATABASE KEEP

Mock Exam 6 · Question 34 RMAN

Which three are true about using an RMAN Recovery Catalog with a pluggable database (PDB) target connection in Oracle Database 19c and later releases? (Choose three.)

📘 官方解析與重點參考
📝 重點筆記參考：
The base catalog owner must give the Virtual Private Catalog access to metadata for one or more PDBs. (基礎目錄的擁有者必須授予虛擬私有目錄 (VPC) 存取一個或多個 PDB 中繼資料的權限。)
存取權限的下放 (Grant Access)：
VPC 裡面一開始是空的。建立 VPC 後，擁有最高權限的「基礎目錄擁有者 (Base Catalog Owner)」必須明確地執行授權指令（例如 GRANT CATALOG FOR DATABASE TO ），VPC 才能真正拿到該 PDB 的備份中繼資料。
