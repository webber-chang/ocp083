Mock Exam 9 · Question 17 RMAN

Which three are true about using an RMAN Recovery Catalog with a pluggable database (PDB) target connection in Oracle Database 19c and later releases? (Choose three.)

📘 官方解析與重點參考
📝 重點筆記參考：
正確選項分析：
註冊於基礎目錄 (Registered in a base catalog)： 這是所有目錄管理的源頭。無論您要切分出多少個 VPC，實體資料庫 (包含 CDB 與其底下的 PDB) 都必須先統一註冊在最底層的「基礎目錄 (Base Catalog)」裡面。
啟用 VPC 支援 (Enabled for VPC use)： 在基礎目錄建立後，預設並未開啟 VPC 功能。DBA 必須執行特定的設定步驟（例如升級目錄結構或建立 VPC 擁有者並授權），才能讓這個基礎目錄支援 VPC 的運作機制。
由擁有者授權 (Give access to metadata)： VPC 的本質是「資料列層級的存取控制」。基礎目錄擁有者必須透過指令 (如 GRANT CATALOG FOR DATABASE TO ;)，明確地將特定 PDB 的備份資料視野，授權給該 VPC 的擁有者。
錯誤選項陷阱分析 (為什麼您的選項與其他不能選)：
The base catalog must be used by RMAN when performing point-in-time recovery for the PDB... (您誤選的項目)
錯誤原因： 建立 VPC 的最大目的，就是要讓 PDB 的本機管理員 (Local DBA) 可以獨立自主地進行備份與還原！當 PDB 管理員連線到他們的 VPC 時，完全有權限自己執行該 PDB 的時間點復原 (PITR)，不需要強制退回到使用 Base Catalog 才能做。
The target PDB must be registered in both the base catalog and the Virtual Private Catalog.
The target PDB must be registered in a Virtual Private Catalog.
錯誤原因： 「註冊 (Register)」這個實體動作只會發生在基礎目錄上一次。VPC 只是基礎目錄上方的一個「受限視圖 (Restricted View)」，您不需要（也無法）在 VPC 裡面「再次註冊」同一個 PDB。

Mock Exam 11 · Question 45 RMAN

Which three are true about Recovery Manager (RMAN) in Oracle Database 19c and later releases? (Choose three.)

📘 官方解析與重點參考
📝 重點筆記參考：
Virtual Private Catalog題型要注意
It is always possible for RMAN to connect to a pluggable database as a target. (RMAN 總是能夠以「目標資料庫 (Target)」的方式連線到 PDB。) - 您漏勾了這個，反而誤勾了帶有條件限制的選項。
It is always possible for RMAN to connect... if any RMAN Catalog is used. (您誤選的選項)

錯誤原因： 畫蛇添足的條件限制。RMAN 連線到 PDB 作為 Target 根本不需要依賴任何 RMAN Catalog。預設情況下，備份資訊會記錄在目標資料庫的 Control File 裡。加上 if... 條件反而扭曲了這個原生功能。

Mock Exam 12 · Question 1 RMAN

You have configured RMAN SBT channels to write backups to media.
You then take an RMAN backup by using this command:
RMAN> BACKUP AS COMPRESSED BACKUPSET
                                    DATABASE
                                    KEEP UNTIL TIME ‘SYSDATE + 730‘
                                    RESTORE POINT ‘OLD_CONFIGURATION‘ ;
Which three are true? (Choose three.)

📘 官方解析與重點參考
📝 重點筆記參考：
The data file backups in the self-contained archive backup are not considered obsolete for two years regardless of the retention policy
一般 RMAN 的保留原則 (Retention Policy) 可能是保留 7 天或 2 份備份。但 KEEP UNTIL TIME 'SYSDATE + 730' 就像是給了這份備份一張為期兩年的「免死金牌」。在這 730 天內，不管您怎麼下達 DELETE OBSOLETE 指令，RMAN 絕對不會把這份特定的備份刪除。
